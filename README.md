# Automação de Relatórios com Python

Projeto demonstrativo de automação desenvolvido em Python.

A proposta surgiu a partir da identificação de uma atividade manual e repetitiva, envolvendo a extração diária de oito relatórios. A automação permite reduzir o tempo dedicado ao processo e direcionar a atenção para outras demandas importantes.

## Objetivos

- Automatizar tarefas repetitivas
- Reduzir o tempo de execução
- Padronizar o processo
- Aplicar conhecimentos de Python
- Gerar mais disponibilidade para atividades estratégicas

## Tecnologias utilizadas

- Python
- Automação de processos
- Microsoft Copilot como apoio na revisão e no ajuste do código

## Observação

Este repositório contém somente uma versão demonstrativa do projeto. Não há dados reais, credenciais, informações internas ou códigos pertencentes à empresa.
